# 默认值裁决记录

> 用途：两条规则给出不同数值时，这里给出唯一默认值。没有记录在案的冲突，一律先停下标【待确认】，不要自行合并。

---

## 已裁决

### C1 行宽
- **默认**：桌面正文 60–75 字符，移动 35–60，任何正文不超过 80。
- **理由**：三处数值分别约束阅读舒适区、设备宽度与上限，取交集后仍可执行。

### C2 逐项入场动画
- **默认**：首屏与正文段落禁用 stagger；仅"列表加载完成"允许 30–50ms 单项延迟。
- **理由**：整页逐节入场是最容易被识别为模板的特征，首屏尤其明显。

### C3 导航层级
- **默认**：不设 3 层硬上限；按信息气味与导航可见性判定（每层入口可预测、深页可回主导航）。
- **理由**：层数上限在内容复杂时会把类目压成模糊词。

### C4 确认弹窗 vs 撤销
- **默认**：顺序固定为 可供性 → 可撤销 → 安全网 → 确认 → 警告；确认框只用于不可逆且无撤销的高危动作，按钮用动词。
- **理由**：先给退路再给弹窗，能减少打断且降低误操作成本。

### C5 toast 的适用面
- **默认**：toast 只用于"用户刚完成的动作"确认；进度、保存状态、在线状态一律用常驻区域。

### C6 目标尺寸
- **默认**：鼠标为主的桌面页面最小 24×24 CSS px；触屏（含平板、移动、触控笔记本）44×44pt / 48dp。

### C7 预设主题
- **默认**：不使用预设主题；用户明确要求时再用，并在交付说明里写清牺牲了哪些独特性。

### C8 品牌色
- **默认**：不得把某个品牌的既有 accent 色当作通用默认色（例如陶土橙）；只在为该品牌做产物时使用。

### C9 远端规则
- **默认**：禁止任何运行时远端抓取；规则只以本 Skill 的 `references/` 为准。

### C10 字体数量
- **默认**：每页 ≥2 套艺术字体承担展示层 + 1 套高可读正文体；艺术体禁用于正文段落。
- **底线**：正文 ≥16px、行高 1.5–1.75、行宽按 C1。
